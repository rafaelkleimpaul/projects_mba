# Vehicle Sales Dashboard

Projeto desenvolvido durante a Sprint 4 do curso de Data Science, com o objetivo de praticar conceitos e ferramentas de engenharia de software aplicados a um projeto de análise de dados.

## Sobre o projeto

Este projeto utiliza um conjunto de dados de anúncios de vendas de veículos para construir uma aplicação web interativa.

A aplicação permite visualizar informações do conjunto de dados por meio de gráficos interativos, facilitando a exploração de características como quilometragem e preço dos veículos.

## Funcionalidades

- Visualização da distribuição da quilometragem dos veículos através de um histograma.
- Visualização da relação entre quilometragem e preço através de um gráfico de dispersão.
- Gráficos interativos utilizando Plotly.
- Interface web desenvolvida com Streamlit.

## Tecnologias utilizadas

- Python
- Pandas
- Plotly Express
- Streamlit
- Jupyter Notebook
- Git e GitHub
- Render

## Estrutura do projeto

- `app.py` — aplicação web desenvolvida com Streamlit.
- `data/vehicles.csv` — conjunto de dados utilizado pelo projeto.
- `notebooks/EDA.ipynb` — notebook utilizado para análise exploratória e testes das visualizações.
- `requirements.txt` — dependências necessárias para executar o projeto.
- `.streamlit/config.toml` — configurações utilizadas para execução da aplicação no Render.

## Executando o projeto localmente

Com as dependências instaladas, execute a aplicação através do terminal:

`streamlit run app.py`

Após executar o comando, a aplicação será disponibilizada localmente pelo Streamlit.
